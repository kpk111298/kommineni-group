# Control Room

A private app that sets what each day looks like across Kommineni Group.

Planned:
- Pick a division, a date range and a volume level
- Switch on a scenario from [docs/scenarios.md](../docs/scenarios.md), such as Black Friday or a supplier file format change
- See which problem each scenario maps to
- Trigger the daily GitHub Action on demand

Runs on Streamlit Community Cloud, locked behind Cloudflare Access so only Prameel can use it.
