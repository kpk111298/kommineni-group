# Divisions

Each division runs on its own. Open its folder and follow its README.

- `meel-motors/`: car dealership. Formerly Kommineni Automotive, so the code and dashboard still use that name. The live dashboard and daily refresh still run from the original repo `kpk111298/kommineni-automotive-pipeline` until they move here.
- `meel-cart/`: online store with incremental loading.
