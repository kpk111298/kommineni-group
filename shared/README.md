# Shared company data

Company-wide data every division uses. Planned:

- `customers`: one person, many accounts across divisions
- `employees`: HR list with transfers and promotions over time
- `locations`: branches, warehouses, offices
- `calendar`: dates, fiscal months, holidays
- `world`: real public data such as interest rates, gas prices, weather, recalls and exchange rates (see ../docs/real-world-data.md)

Right now Meel Motors and Meel Cart each create their own copies. Moving them here is part of the roadmap.
